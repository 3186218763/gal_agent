# Keep Ending Semantics Open

A Script Pack defines fictional boundaries, dramatic concerns, and a Completion Contract, but it does not enumerate the possible endings. Every playthrough must reach a Dynamic Ending within its authored length bound; the engine enforces Ending Integrity, while the Agent derives the exact terminal outcome from Committed History. A playthrough may end without satisfying the Completion Contract, because bounded convergence and completion are separate properties.

This preserves the platform's core promise that a playthrough can arrive somewhere the author did not prewrite. The trade-off is that reliability must come from hard state and causal constraints plus bounded semantic evaluation, not from selecting a known ending route. Generation failures therefore do not commit placeholder story events or consume the playthrough's length budget.
