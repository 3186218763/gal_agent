# Commit Choice Meaning Before Consequences

Every presented Player Choice carries stable Choice Meaning that the player can understand before selecting it. Selection commits that meaning first; an Agent may then propose a concrete Story Consequence, but the deterministic kernel must validate its causal connection and authored bounds before prose is accepted. This prevents a later model call from reinterpreting or silently ignoring the player's only input, at the cost of requiring richer structured choice and consequence contracts.
