# Script Pack 2.0 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the script-pack schema to support v2.0 packs with `completion_requirements`, `world_setting`, `story_history`, and `opening_state` while maintaining v1.0 backward compatibility, and centralize test fakes.

**Architecture:** The `ScriptPackSource` model gains a discriminated union on `schema_version`: v1.0 packs keep `world` + `endings`; v2.0 packs use `world_setting` + `story_history` + `opening_state` + `completion_requirements` and must NOT contain `endings`. The compiler branches on schema version: v1.0 retains the three-normal-plus-fallback rule; v2.0 skips it and instead validates completion requirements and evidence hint references. `CompiledScriptPack` gains `completion_requirement_ids` for downstream Plans 2-4.

**Tech Stack:** Python 3.11+, Pydantic v2 (`StrictModel`, `model_validator`, discriminated unions), pytest, PyYAML

## Global Constraints

- All new models extend `StrictModel` (Pydantic v2, `extra="forbid"`, `frozen=True`)
- All ID fields use `SafeId` (`^[a-z][a-z0-9_]{1,63}$`)
- `schema_version` field becomes `Literal["1.0", "2.0"]`
- v2.0 packs must NOT contain `endings`; compiler rejects them with `PackCompileError`
- v2.0 packs must contain `completion_requirements` with `min_length=1`
- v1.0 packs remain unchanged: `world` (with `initial_situation`) + `endings` required, no `completion_requirements`
- `CompiledScriptPack` is the single compiled artifact; downstream plans import it
- Cross-plan type names (defined in "CROSS-PLAN SHARED TYPES" above) are authoritative
- Ruff lint must pass: `uv run ruff check src/story tests`
- All tests must pass: `uv run pytest tests/ -x`
- No placeholders, no TODOs, no deferred implementations

- [ ] **Step 4: Create the union `ScriptPackSource` as a BaseModel**

In `backend/src/story/script_pack/models.py`, replace the old `ScriptPackSource` class with a real BaseModel that validates as v1.0 or v2.0 based on `schema_version`. This preserves `model_validate()` compatibility which the Annotated union approach breaks:

```python
class ScriptPackSource(StrictModel):
    """Discriminated union of v1.0 and v2.0 pack sources via schema_version."""
    model_config = ConfigDict(extra='forbid', frozen=True)

    @model_validator(mode='before')
    @classmethod
    def _dispatch_by_version(cls, data):
        if isinstance(data, (ScriptPackSourceV1, ScriptPackSourceV2)):
            return data
        if isinstance(data, dict):
            version = data.get('schema_version')
            if version == '1.0':
                return ScriptPackSourceV1.model_validate(data)
            elif version == '2.0':
                return ScriptPackSourceV2.model_validate(data)
            raise ValueError(f'Unknown schema_version: {version}')
        raise ValueError(f'Cannot validate {type(data)} as ScriptPackSource')
```

This makes `ScriptPackSource` a real Pydantic model that dispatches to V1 or V2. All downstream code using `ScriptPackSource.model_validate()` continues to work without changes.

    """Yield condition key/expression pairs for v2.0 packs (no ending conditions)."""

    if isinstance(raw, ScriptPackSource):
        source = raw
    else:
        try:
            source = ScriptPackSourceV1.model_validate(raw) if raw.get("schema_version", "1.0") == "1.0" else ScriptPackSourceV2.model_validate(raw)
        except ValidationError as exc:
            raise PackCompileError(str(exc)) from exc

    character_ids = {item.id for item in source.characters}
    fixed_ids = {item.id for item in source.facts.fixed}
    latent_ids = {item.id for item in source.facts.latent_questions}
    derived_ids = {item.id for item in source.facts.derived}
    fact_ids = fixed_ids | latent_ids | derived_ids
    goal_ids = {item.id for item in source.goals}
    extension_id_values = [item.id for item in source.interaction_rules.extensions]
    extension_ids = set(extension_id_values)
    action_ids = (
        set(source.interaction_rules.enabled_standard) | extension_ids
    ) - set(source.interaction_rules.disabled)

    errors: list[str] = []
    errors.extend(_duplicate_ids("character", (item.id for item in source.characters)))
    fact_id_values = [
        *(item.id for item in source.facts.fixed),
        *(item.id for item in source.facts.latent_questions),
        *(item.id for item in source.facts.derived),
    ]
    errors.extend(_duplicate_ids("fact", fact_id_values))
    errors.extend(_duplicate_ids("goal", (item.id for item in source.goals)))
    errors.extend(_duplicate_ids("location", (item.id for item in _pack_locations(source))))
    errors.extend(_duplicate_ids("faction", (item.id for item in _pack_factions(source))))
    errors.extend(_duplicate_ids("action", extension_id_values))
    if source.protagonist.id in character_ids:
        errors.append(f"protagonist id collides with character id: {source.protagonist.id}")
    errors.extend(
        f"action extension cannot replace standard action: {item}"
        for item in sorted(extension_ids & STANDARD_ACTION_IDS)
    )

    unknown_standard = set(source.interaction_rules.enabled_standard) - STANDARD_ACTION_IDS
    errors.extend(f"unknown standard action: {item}" for item in sorted(unknown_standard))
    unknown_disabled = set(source.interaction_rules.disabled) - (
        STANDARD_ACTION_IDS | extension_ids
    )
    errors.extend(f"unknown disabled action: {item}" for item in sorted(unknown_disabled))

    # --- Schema-version-specific validation ---
    is_v2 = isinstance(source, ScriptPackSourceV2)

    if is_v2:
        errors.extend(_duplicate_ids(
            "completion_requirement",
            (req.id for req in source.completion_requirements),
        ))
        errors.extend(
            _v2_reference_errors(source, character_ids, fixed_ids, fact_ids, goal_ids)

    else:

        normal_endings = [item for item in source.endings if item.type != "fallback"]
        fallback_endings = [item for item in source.endings if item.type == "fallback"]
        if len(normal_endings) < 3:

        if not fallback_endings:
            errors.append("script pack requires at least 1 fallback ending")

        errors.extend(
            _reference_errors(source, character_ids, fixed_ids, fact_ids, goal_ids, action_ids)
        )
        programs, condition_errors = _compile_programs(source)
        ending_ids = {item.id for item in source.endings}
        completion_requirement_ids: set[str] = set()

    errors.extend(condition_errors)

    if not is_v2 and not condition_errors and not _has_guaranteed_fallback(source, programs):

    ).encode("utf-8")

    return CompiledScriptPack(

        character_ids=frozenset(character_ids),
        fact_ids=frozenset(fact_ids),
        goal_ids=frozenset(goal_ids),
        ending_ids=frozenset(ending_ids),
        completion_requirement_ids=frozenset(completion_requirement_ids),
