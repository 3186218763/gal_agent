# 第一章：邂逅

## Beat 1: 开场
**Mood**: 平静，略带神秘

午后的咖啡馆里，阳光透过落地窗洒在木质地板上。你独自坐在靠窗的位置，手里拿着一杯拿铁，等待着约好的朋友。

窗外的街道上人来人往，一切都显得如此寻常。

## Beat 2: 艾丽丝登场
**Mood**: 紧张感上升

突然，一个陌生女孩快步走到你的桌前，没有征询就坐在了对面的位置。

她有着一头棕色的短发，穿着休闲的牛仔外套。她的眼神闪烁不定，似乎在确认周围没有人注意。

"不好意思，"她压低声音说，"我知道你在找什么。"

你愣住了。这个人你从未见过。

## Beat 3: 艾丽丝的情报
**Mood**: 紧张

"我叫艾丽丝，"她说，"最近我发现了一些...奇怪的事情。关于那个组织的事。"

她从包里拿出一个旧式的笔记本，快速翻到某一页，上面写满了密密麻麻的笔记。

"你看，这些线索都指向同一个地方。我一个人查不下去了，需要有人帮忙。"

艾丽丝的眼神中充满了恳切，但也有一丝你无法读懂的情绪。

Set flag: `talked_to_alice = true`

## Beat 4: 鲍勃介入
**Mood**: 冲突

就在这时，另一个男人走了过来。他穿着整洁的黑色外套，表情严肃。

"艾丽丝，又是你。"他的声音冷静而带着警告，"你不应该把无关的人卷进来。"

他转向你："我是鲍勃。不管她跟你说了什么，我建议你不要相信。艾丽丝经常...夸大事实。"

艾丽丝猛地站起来："鲍勃！你才是在隐瞒真相！"

两人之间的气氛剑拔弩张。

Set flag: `met_bob = true`

Character interaction: Alice 和 Bob 之间有明显的敌意和不信任。

[OPTION POINT - 高优先级：相信艾丽丝/相信鲍勃/保持中立]

## Beat 5: 紧张对峙
**Mood**: 高度紧张

咖啡馆里的其他客人开始注意到这边的动静。

鲍勃深吸一口气，努力让自己冷静下来："听着，我不是来吵架的。艾丽丝，如果你真的在意这件事，就应该更谨慎。"

他看向你："你叫什么名字？既然已经卷进来了，至少应该知道自己面对的是什么。"

艾丽丝也坐了回去，但她的手紧紧握着那本笔记本。

气氛依然紧绷，但暂时平息了下来。

## Beat 6: 决定时刻
**Mood**: 沉重的选择感

现在，两个人都在等你的回答。

艾丽丝说她发现了重要线索，需要你的帮助。她看起来真诚，但也有些冲动。

鲍勃则警告你要小心，他声称艾丽丝的做法太危险。他显得理性，但也可能在隐藏什么。

你需要做出选择——相信谁？或者，暂时不相信任何人？

窗外的阳光渐渐西斜，咖啡馆里的时间仿佛凝固了。
